# DocQueue: Android download

Book a doctor's serial and track the live queue from your phone.

## Install

1. On your Android phone (Android 7 or newer), open:
   **https://github.com/tarikuldev/docqueue-download/releases/latest/download/DocQueue.apk**
2. Open the downloaded file and allow **Install unknown apps** for your browser when asked.
3. Open **DocQueue**.

The link always points to the newest version. New versions install as an update over the old one.

## Current version

**1.0.0 (demo mode):** runs fully offline with sample doctors. Sign in with any Bangladeshi mobile number, for example `01712345678`, and code **123456**.

This repository only hosts the app download.
