# DocQueue: Android download

Book a doctor's serial and track the live queue from your phone.

## Install

1. On your Android phone (Android 7 or newer), open:
   **https://github.com/tarikuldev/docqueue-download/releases/latest/download/DocQueue.apk**
2. Open the downloaded file and allow **Install unknown apps** for your browser when asked.
3. Open **DocQueue**.

The link always points to the newest version. From 1.0.2 on, the app finds and installs new versions by itself.

## Current version

**1.1.0 (demo mode):** all-new *Clinical Midnight* design with an animated logo, glass cards, tilting date picker, glowing hold countdown and a live queue path. DocQueue updates itself: tap **Update** when a new version is out. Runs fully offline with sample doctors.
